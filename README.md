# Онлайн-магазин (Симулятор БД) в Docker

Простой фоновый демон-сервис на **C# (.NET 10)**, который симулирует работу онлайн-магазина, считывая остатки товаров из файловой базы данных `database.txt` и выводя отчет в логи.

## 🚀 Инструкция по запуску

Выполните следующие команды в терминале для сборки и запуска проекта в изолированном контейнере:

### 1. Сборка Docker-образа
```bash
docker build -t my-shop-app .
```

### 2. Запуск контейнера в фоновом режиме
```bash
docker run -d --name shop-container my-shop-app
```

### 3. Проверка работы приложения (Просмотр логов)
```bash
docker logs shop-container
```

---

## 📂 Структура проекта

* `Program.cs` — логика фонового чтения БД в бесконечном цикле.
* `database.txt` — текстовый файл-база данных (Формат: `ID,Название,Цена,Количество`).
* `Dockerfile` — многоэтапный файл сборки (Multi-stage build) на базе образов Microsoft .NET 10.
